# 本地曲库

此目录是口琴工坊的默认曲库位置。GitHub 源码仓库仅保留本说明，不提供第三方歌曲或本机曲库记录。

## 添加曲谱

1. 将自己的 `.mid`、`.midi`、`.kar` 或 `.rmi` 文件直接放入本目录。
2. 在程序的“曲库”中选择曲目；未出现时点击“刷新”。
3. 如需使用其他位置，在曲库设置中选择外部文件夹。

程序只扫描所选目录的直接子文件，不扫描子文件夹。请勿将需要显示的曲谱放入下级目录。

## 可选资料

`catalog.json` 可提供曲名和预设选轨资料，不是添加歌曲的必需文件。没有该文件也可以扫描并打开 MIDI。

来源说明、原谱图片及转谱记录可以保留在本机，供个人核对；它们不作为当前曲库数量、转换结果或测试通过情况的证明。

## Git 与便携版

本目录除 `README.md` 外的文件均由仓库根目录的 `.gitignore` 排除。已有的本地曲谱与资料不会因此被删除，也不会随普通 Git 提交上传。

便携版使用外层 `HarmonicaStudio/samples/` 作为默认曲库；已有曲库文件在受保护的升级流程中保留。源码目录与便携版目录是不同位置，详情见 [项目 README](../README.md)。
