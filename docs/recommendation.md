# 声部推荐与音域适配（2.1.12）

推荐指数仍是 0–100 的启发式偏好，不是主旋律概率。GUI 声部排序、CLI `inspect` 和未指定声部时的转换均使用 `rank_parts`；转换参数不会改变这个排名。

## 特征与评分

- **忙碌度**：对起音分组，使用相邻起音间隔的中位数计算典型局部频率；超过每秒 8 次起音才开始扣分。音符松开的时间不参与分母，短促断奏不会因发声时间少而被误判为高密度。
- **单音程度**：对音符区间扫描，统计重叠时间占比。仅在相邻两组都只有一个音符、前音结束早于后音结束时，允许不超过 80 毫秒且不超过起音间隔 20% 的尾部重叠。同起音和弦、持续复音不享受这个容差。容差只作用于特征区间，原始音符不变。
- **覆盖率**：按声部自己的进入时间划分 4 秒区间，计算含起音的区间占比；声部跨度相对全曲的覆盖只以一个弱权重参与评分，不再额外乘一次全曲覆盖率。内部大段空白仍降低分段活跃度。
- **伴奏线索**：考察 1–8 个起音间隔的短周期，至少需要三个周期，音高间隔和节奏都匹配才计重复。再结合三度至八度的跳进比例、起音频率以及同曲相对音区形成有限扣分。重复级进旋律不会仅因重复被判为伴奏。
- **其余线索**：保留旋律连续性、音高多样性、绝对音区和音符数量证据；轨名仅作小幅提示。短碎片和单个长音仍不能仅靠单音程度胜出。并列按轨道/通道键稳定排序。

基础权重为单音程度 32、分段活跃度 18、连续性 14、音区 14、多样性 12、全曲跨度 10；轨名最多增减 4，伴奏辅助扣分最多 16，繁忙扣分最多 8。样本数量不足时缩减证据强度。每项有明确上限，最终限制在 0–100。

## 与实际转换共用的适配

`melody::fit_part` 是单声部提取与适配的共享入口，`prepare` 和 CLI 检查都调用它：

1. 按实际 `melody_mode` 提取。
2. 应用指定移调、自动八度、乐句八度，再按速度处理时间。
3. 返回实际音符和报告；全部越界时可以报告零保留，正式转换仍拒绝空结果。

报告新增 `extracted_notes`、`range_retention` 和 `source_retention`。前者保留率的分母是**提取后的音符数**，后者是**原声部音符数**；两者都按音符数量计算，不是按时长加权。旧报告字段继续保留。GUI 与 CLI 转换输出同样的报告；GUI 的“推荐指数”仍只表示旋律偏好，不表示当前参数下可演奏的比例。

```powershell
.\HarmonicaStudio.exe inspect .\example.mid
.\HarmonicaStudio.exe inspect .\example.mid --mode continuous --transpose -12 --no-auto-octave --phrase-octave
```

`inspect` 保留原数组结构和推荐字段，额外输出 `fit`、`fit_options`。改变适配选项只改变适配字段。检查保留率不代替完整导出校验。

## 固定样本前后对照

样本由 `tests/core_contracts/recommendation.rs` 确定生成，前后使用同一音符输入和空轨名。每个场景包含目标旋律与分解和弦两个候选。

| 场景 | 旧：旋律 / 伴奏分数 | 新：旋律 / 伴奏分数 | 目标旋律排名 |
| --- | --- | --- | --- |
| 分解和弦对照 | 94.4 / 93.9 | 98.1 / 82.8 | 1 → 1 |
| 旋律晚 40 秒进入 | 78.7 / 94.1 | 94.8 / 82.8 | 2 → 1 |
| 60 毫秒连奏尾部 | 95.3 / 93.9 | 96.1 / 82.8 | 1 → 1 |
| 每秒一音、40 毫秒断奏 | 50.3 / 93.9 | 98.2 / 82.8 | 2 → 1 |

测试还覆盖真正和弦/持续重叠、起音频率不受释放长度影响、重复级进旋律、内部长空白、输入逆序和原时间不变，以及 72 组提取/移调/八度/速度组合与实际转换结果的一致性。实际 CLI 子进程检查验证了默认参数兼容和适配字段独立性。

## 验证范围与局限

这些是针对已知失效模式设计的合成回归，不是独立音乐测试集。仓库没有经过确认的人工主旋律标注集；本地 catalog 与历史测试是转换兼容记录，不作为人工准确率标签。因此不报告真实曲库 Top-1/Top-3；两个候选的合成案例计算 Top-3 也没有区分意义。

启发式仍可能误判低音主旋律、反复跳进的主题、旋律型伴奏及轮流领奏。固定秒数的窗口/容差不等同于节拍分析；中位起音间隔可能低估少数突发快音段。四秒分段边界、音区线索和人工权重仍有偏差。适配保留率衡量可保留音符数量，不代表乐句质量、游戏响应或听感。后续应采用人工标注、多种体裁、允许多个正确声部的独立曲库统计 Top-1/Top-3，并与调参样本分离。
